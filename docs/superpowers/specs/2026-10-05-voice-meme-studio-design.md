# 声音表情包工坊设计说明

## 目标

构建一个完全在浏览器运行的 Vue 3 声音创作工具。用户可录制或导入最长 10 秒音频，获得基于声学特征的情绪标签，编辑 Canvas 表情包封面，收藏作品并导出或分享音频与封面。

## 技术与工程约束

- Vue 3、TypeScript、Vite、Vitest；仅使用原生 CSS。
- 使用浏览器 MediaRecorder、Web Audio、Canvas、IndexedDB、Web Share 和下载 API，不调用远程 AI 或后端服务。
- 项目拥有独立 Git 仓库、README、Dockerfile、docker-compose.yml 和 Nginx 单页应用配置。
- 生产镜像默认映射到宿主机端口 `8105`。
- 采用核心层、端口层、适配器层、界面层四层结构。

## 产品范围

### 录音室

应用请求麦克风权限后录制最长 10 秒音频，显示倒计时、实时音量条、暂停和结束状态。达到上限自动停止。用户也可导入浏览器支持的音频文件；超过 10 秒时提示裁剪。权限拒绝、无录音能力和输入设备异常均显示明确恢复建议。

### 音频裁剪与回放

使用 Web Audio 解码音频，用户通过起止滑块选择不超过 10 秒的片段，可试听裁剪结果并恢复原始范围。最终作品保存裁剪后的 Blob，而不是仅保存时间标记。

### 裁剪后的音量与首尾淡化

裁剪确认后，保留片段成为唯一处理基准，用户可调整线性增益（0~2 倍）与头部淡入、尾部淡出秒数，原声与处理后声音可分别回放对比。所有处理均由 `src/core/audio-effects.ts` 从保留片段的 PCM 重新计算，从不基于上一次的输出迭代，因此不会累积放大误差。淡化长度夹取在 `fadeIn + fadeOut <= 片段时长` 范围内，既不越过边界也不相互交叠；增益超过满幅的样本硬限制为 ±1，并报告削波样本占比。

试听、较重处理与最终确认按三级分工，避免拖动时逐次完整处理积压：

- **拖动中（轻）**：只更新参数与“原峰值 × 增益”的削波预判，零渲染，保证滑块跟手。
- **停顿后（中）**：120ms 去抖触发一次只写内存的 PCM 渲染（不编码、不落盘）。调度采用世代令牌 + 单一在途 + 单一待执行槽：快速拖动不断重排同一个停顿定时器；在途期间到达的更新只保留最后一次参数；旧世代结果晚返回时连同可能的排队任务一并作废或转交，绝不覆盖更新的试听。
- **确认采用（重）**：点击“采用效果并分析”时，以保留片段做一次权威渲染并同步编码 WAV。情绪分析与保存只消费这次确认产生的 Blob。

“听效果”按钮不等待去抖与在途任务，直接按当前滑块参数渲染并播放，因此任何时刻都能立即试听最新参数；代价是同一参数可能渲染两次（一次用于播放、一次用于去抖后的指示数据），但渲染仅为内存级纯计算。确认之后若又改动滑块，确认 Blob 与当前参数不再同源，界面标记为脏并在保存前拦截，要求重新采用，避免把较早参数的音频与最新参数一起保存。分析失败、保存失败或返回裁剪都只丢弃中间结果：保留片段、裁剪范围、滑块参数与已确认 Blob 仍可恢复。

### 情绪识别

分析模块从音频样本计算 RMS 平均音量、音量动态范围、估算基频中位数、过零率、停顿比例和节奏变化。规则引擎将归一化特征映射到“暴躁老哥”“温柔姐姐”“阴阳怪气”“元气满满”四类标签，并提供置信度和一句可解释说明。识别是娱乐性启发式结果，界面明确说明不是身份、性格或医学判断；用户可以手动改选标签。

### 封面工坊

Canvas 按当前情绪生成配色、放射纹理、波形装饰和标签章。用户可编辑主文案、文字气泡位置与样式，选择黑白、高饱和、暖调、冷调滤镜，并在方形和竖版卡片比例间切换。所有绘制逻辑通过渲染端口接收纯配置，便于测试和替换。

### 作品集

作品包含标题、情绪、特征摘要、音频 Blob、时长、封面 Blob、编辑配置和创建时间。元数据及 Blob 保存到 IndexedDB；作品集支持播放、重命名、删除、再次编辑和按情绪筛选。首次进入提供一张无音频的示例卡片，用于解释操作方式。

### 分享与导出

用户可以分别下载音频和 PNG 封面，也可下载包含元数据的作品 JSON。浏览器支持 `navigator.share` 且允许文件分享时，直接分享音频与封面；不支持时回退到下载。

纯前端无法提供公共音频托管，因此“生成分享链接”只编码标题、情绪、文案、配色和封面参数到 URL fragment，用于重建预览卡片，不在链接中塞入音频。界面会明确标注链接不包含原始声音，并提供“同时分享文件”操作。

## 架构

- `src/core`：作品与声学特征模型、特征归一化、情绪规则、裁剪范围校验、封面配置生成。
- `src/ports`：录音、音频分析、音频裁剪、封面渲染、作品仓储、分享/下载端口。
- `src/adapters`：MediaRecorder、Web Audio、Canvas、IndexedDB、Web Share/下载实现。
- `src/ui`：Vue 工作流组件、组合式控制器和原生 CSS。

核心层仅处理数值、规则和序列化配置；浏览器 API 均封装在适配器中。录音状态机禁止在录音未完成时进入封面导出。

## 状态与数据流

流程为“录制/导入 → 裁剪 → 分析 → 确认情绪 → 编辑封面 → 保存/分享”。每个阶段保留可返回修改的状态。页面刷新后只恢复已保存作品，不自动保存未完成录音，以避免在用户不知情时持久化声音。

## 交互与视觉

整体采用“声音贴纸工作台”风格：深紫背景、酸性黄与电光粉强调、大号波形和层叠贴纸。桌面端左侧为时间线与参数，右侧为实时封面；移动端改为阶段式流程。录音按钮和状态不可只用颜色表达，必须同时提供文字与图标。

## 测试与验收

- 单元测试覆盖特征归一化、四类情绪映射、低音量/全静音、裁剪边界、分享载荷编码解码。
- 适配器测试使用浏览器能力替身覆盖权限拒绝、录音自动停止、IndexedDB 存取和分享回退。
- 验收需通过 `npm test`、`npm run build`，并人工验证真实麦克风录制、Canvas 导出、刷新后收藏恢复及 Docker 构建。

## 非目标

不实现语音转文字、说话人身份识别、机器学习模型训练、公共文件托管、跨设备收藏同步或服务器短链接。
